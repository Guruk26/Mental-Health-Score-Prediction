# Mental-Health-Score-Prediction

MindScope is a machine-learning-based Mental Stress Score Prediction system. The user enters personal, academic, social-media usage, lifestyle, and stress-related information through an interactive web interface. The frontend sends these details as JSON to a FastAPI backend. The backend preprocesses the input, loads the trained machine-learning model, generates a mental-health score, and returns the prediction to the frontend. The result is then displayed through an interactive score meter with a simple explanation.
